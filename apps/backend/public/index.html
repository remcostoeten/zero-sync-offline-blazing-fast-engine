Finance API

The Finance API provides comprehensive endpoints for managing categories, transactions, budgets, recurring transactions, and savings goals with real-time tracking.

GET /api/finance/categories Auth Stable

List categories

Returns a list of all categories with optional type filtering.

Query Parameters
Parameter Type Description
type string Filter categories by type (income, expense)
Example Request 
curl -X GET
                        "http://localhost:4000/api/finance/categories?type=expense" \
                        -H "Content-Type: application/json"
Example Response

                        "success": true,
                        "data": [

POST /api/finance/categories Auth Stable

Create category

Creates a new category for transactions.

Request Body
Parameter Type Description
name required string The name of the category
type required string Category type (income, expense)
color required string Color code (hex) for the category
Example Request 
curl -X POST "http://localhost:4000/api/finance/categories" \
                        -H "Content-Type: application/json" \
                        -d '{
                        "name": "Entertainment",
                        "type": "expense",
                        "color": "#9c27b0"
                        }'
Example Response 
{
                        "success": true,
                        "data": {
                        "id": 3,
                        "name": "Entertainment",
                        "type": "expense",
                        "color": "#9c27b0",
                        "createdAt": "2024-01-15T14:22:31Z",
                        "updatedAt": "2024-01-15T14:22:31Z"
                        }
                        }
GET /api/finance/transactions Auth Stable

List transactions

Returns a list of transactions with optional filtering and pagination.

Query Parameters
Parameter Type Description
categoryId number Filter by category ID
startDate string Filter by start date (ISO format)
endDate string Filter by end date (ISO format)
page number Page number for pagination
limit number Number of items per page
Example Request 
curl -X GET
                        "http://localhost:4000/api/finance/transactions?startDate=2024-01-01&endDate=2024-01-31&page=1&limit=10"
                        \
                        -H "Content-Type: application/json"

Database Studio API

The Database Studio API provides comprehensive tools for managing connections to LibSQL, SQLite, and PostgreSQL databases, with table browsing, query execution, and more.

POST /api/database-studio/connections Auth Stable

Create connection

Creates a new database connection.

Request Body
Parameter Type Description
name required string Connection name
type required string Database type (libsql, sqlite, postgres)
url required string Connection URL or file path
token string Authentication token (for LibSQL)
Example Request 
curl -X POST
                        "http://localhost:4000/api/database-studio/connections" \
                        -H "Content-Type: application/json" \
                        -d '{
                        "name": "Local Finance DB",
                        "type": "libsql",
                        "url": "libsql://finance-db.turso.io",
                        "token": "ey..."
                        }'
Example Response 
{
                        "success": true,
                        "data": {
                        "id": 1,
                        "name": "Local Finance DB",
                        "type": "libsql",
                        "url": "libsql://finance-db.turso.io",
                        "isFavorite": false,
                        "createdAt": "2024-01-15T16:42:31Z",
                        "updatedAt": "2024-01-15T16:42:31Z"
                        }
                        }
